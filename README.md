# Retail Operations & Profitability Analytics

### Overview
This project provides a comprehensive analysis of 9,000+ sales records to identify growth drivers and operational inefficiencies. By transforming raw transactional data into a structured analytical system, I focused on uncovering the trends behind regional performance from 2015 to 2018.

### Core Analytical Contributions
* **Data Integrity:** Executed systematic cleaning and formatting of 9,000+ records to ensure high-accuracy reporting.
* **Operational Diagnostics:** Identified shipping bottlenecks and regional profitability gaps through multi-year performance benchmarking.
* **Strategic Visualization:** Developed a professional Excel dashboard using "non-data-ink" principles—stripping away borders and clutter to prioritize essential business metrics.

### Technical Toolkit
* **Advanced Excel:** Pivot Table architecture, dynamic formulas, and interactive dashboard design.
* **Analytical Framework:** Applied statistical rigor to trend identification and retail operations.
